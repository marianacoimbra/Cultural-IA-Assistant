# Setup do frontend com React

## Objetivo do bloco

Criar uma interface inicial para o projeto, permitindo que o usuário interaja com o backend e visualize o fluxo principal da aplicação. O frontend será a camada de experiência do usuário e também uma ótima oportunidade para aprender desenvolvimento moderno.

## Por que fazer isso

- O frontend transforma a API em algo visual e utilizável.
- React é uma das ferramentas mais usadas no mercado para interfaces modernas.
- Ter uma interface inicial melhora muito o valor do projeto para portfólio.
- Esse bloco ajuda a aprender comunicação entre frontend e backend, navegação e gerenciamento de estado básico.

---

## Bloco 1 — Definir a estrutura da interface

### O que fazer

- Definir quais telas serão prioritárias no início.
- Pensar em telas como login, cadastro, listagem de eventos e detalhes.
- Montar um fluxo simples de uso do usuário.

### Por que isso é importante

Uma interface sem estrutura clara vira um problema de manutenção. Essa etapa ensina planejamento e UX básica.

### Entregável

Mapa simples das telas e do fluxo de navegação.

---

## Bloco 2 — Preparar o ambiente do frontend

### O que fazer

- Instalar Node.js.
- Criar um projeto React com Vite.
- Configurar a pasta do projeto e as dependências iniciais.

### Por que isso é importante

React com Vite é uma forma moderna e rápida de construir interfaces. Aprender isso te dá uma base prática para projetos futuros.

### Entregável

Projeto React rodando localmente.

---

## Bloco 3 — Criar a interface inicial

### O que fazer

- Criar uma página inicial.
- Adicionar um cabeçalho simples.
- Exibir uma lista de eventos de exemplo.

### Por que isso é importante

Essa etapa ensina como estruturar componentes e como a interface começa a ganhar forma.

### Entregável

Uma tela inicial funcional e visualmente organizada.

---

## Bloco 4 — Conectar com o backend

### O que fazer

- Criar uma camada de serviço para chamadas à API.
- Fazer a aplicação buscar dados do backend.
- Mostrar os dados em tela.

### Por que isso é importante

Essa é uma das habilidades mais relevantes em desenvolvimento full stack: integrar frontend e backend.

### Entregável

Frontend consumindo dados de uma API real.

---

## Bloco 5 — Implementar navegação básica

### O que fazer

- Criar rotas simples para login, cadastro, listagem e detalhe.
- Usar um roteador para navegação.

### Por que isso é importante

Aprender navegação é essencial para qualquer aplicação web moderna.

### Entregável

Fluxo básico com múltiplas telas.

---

## Bloco 6 — Trabalhar experiência de usuário

### O que fazer

- Adicionar estados de carregamento.
- Tratar erros de API.
- Melhorar layout com componentes simples.

### Por que isso é importante

Mesmo um projeto de estudo precisa parecer profissional. Essa etapa ensina a diferença entre “funciona” e “funciona bem”.

### Entregável

Interface mais robusta e amigável.

---

## Bloco 7 — Preparar para demonstração

### O que fazer

- Organizar a interface para mostrar em demo.
- Garantir que o fluxo principal funcione sem esforço.
- Documentar como rodar o frontend e como ele se conecta ao backend.

### Por que isso é importante

Essa etapa ajuda a transformar o projeto em um excelente material para portfólio e entrevistas técnicas.

### Entregável

Frontend pronto para demonstração e apresentação.

---

## Sequência recomendada

1. Definir a estrutura da interface
2. Preparar o ambiente do frontend
3. Criar a interface inicial
4. Conectar com o backend
5. Implementar navegação
6. Melhorar experiência do usuário
7. Preparar para demonstração

## Resultado esperado

Ao final desse bloco, você terá um frontend inicial com telas básicas, integração com a API e um ponto sólido para evoluir com autenticação, favoritos e perfil do usuário.
