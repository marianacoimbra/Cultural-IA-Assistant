# Cultural IA Assistant

A smarter way to discover cultural experiences that actually match your interests.

We live in a world where there is always something happening — but not always something worth attending. Event platforms are crowded, repetitive, and often irrelevant. People spend too much time searching, filtering, and comparing options instead of enjoying the experience itself.

Cultural IA Assistant was created to change that.

This project aims to turn cultural discovery into a more personalized, intelligent, and enjoyable experience. Instead of browsing endless generic lists, users can find events, shows, exhibitions, and experiences that are more aligned with their context, preferences, and location.

## Why this project matters

The problem is simple but very real:

- there are too many events and too little curation;
- most platforms prioritize volume over relevance;
- searches are usually based on keywords, not on real user taste and context;
- people often miss cultural experiences because they are difficult to discover.

Cultural IA Assistant exists to make discovery more natural, more useful, and more human.

## The idea

This product is not just another event listing app.

It is a cultural discovery assistant designed to help users answer questions like:

- What is happening near me this week?
- Which event matches my interests and budget?
- What is worth attending in a city I am visiting?
- Which experiences are more aligned with my profile, mood, and context?

The goal is to combine cultural exploration with personalization, context, and AI-driven recommendation logic.

## What makes it different

### Smarter recommendations
- search by city, area, and interest;
- relevance filters for category, date, distance, and context;
- recommendations tailored to user preferences.

### Better user experience
- casual exploration without forcing sign-up;
- simple interface and quick access to relevant events;
- coherent, friendly, and low-friction UX.

### Future-ready AI layer
- profile-based personalization;
- context awareness based on location and usage patterns;
- explainable recommendations;
- future agent-based intelligent suggestions.

## Tech stack

The project is designed with a modern and scalable architecture:

- Backend: Python + FastAPI
- Frontend: React + Vite
- API documentation: OpenAPI / Swagger
- Local environment: Docker and Docker Compose
- Data layer: PostgreSQL in future iterations
- AI evolution: recommendation services and agent-based intelligence

## Architecture overview

The system is organized in layers so it can evolve without losing clarity:

1. Frontend experience layer
2. Backend API layer
3. Recommendation and interpretation services
4. Data persistence and profile logic
5. AI and agent-based intelligence in future phases

This structure supports a clean MVP while leaving room for more advanced features as the product matures.

## MVP focus

The initial version aims to deliver a functional and highly usable experience for discovering cultural events without mandatory login.

Planned MVP features:

- casual exploration of events;
- city and interest-based search;
- basic event filtering;
- event listing with useful context;
- temporary favorites;
- foundation for personalization in later phases.

## Roadmap

### Phase 1 — Functional MVP
- simple search and discovery interface
- backend support for events and initial profile data
- anonymous visitor flow
- basic favorites

### Phase 2 — Personalization
- user sign-up and login
- interest profile creation
- contextual recommendations
- user interaction history

### Phase 3 — AI and multi-agent layer
- explainable recommendations
- specialized agents for different decision dimensions
- deeper personalization based on behavior and context
- smarter suggestions and prioritization

### Phase 4 — Product expansion
- reminders and notifications
- itinerary planning
- integration with external event sources
- richer, more proactive user experience
