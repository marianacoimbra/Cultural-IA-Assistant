# Roadmap mensal do projeto

## Objetivo geral

Construir um MVP funcional de estudo e portfólio, com foco em valor para o usuário e em boas práticas de desenvolvimento.

## Semana 1 — Fundação

### Meta

Montar a base do projeto e preparar o ambiente de desenvolvimento.

### Tarefas

- [ ] Definir escopo do MVP
- [ ] Escolher stack principal
- [ ] Criar estrutura inicial de pastas
- [ ] Configurar ambiente local com Docker
- [ ] Documentar setup no README

### Entregável

Repositório com estrutura inicial e ambiente rodando localmente.

## Semana 2 — Backend MVP

### Meta

Criar a API principal e o modelo de dados base.

### Tarefas

- [ ] Implementar autenticação básica
- [ ] Criar modelos de usuário, evento e favorito
- [ ] Criar endpoints de cadastro e login
- [ ] Criar endpoints de listagem e busca de eventos
- [ ] Criar testes básicos da API

### Entregável

Backend com fluxo principal funcional e documentado.

## Semana 3 — Frontend MVP

### Meta

Transformar a API em uma experiência simples e navegável.

### Tarefas

- [ ] Criar layout inicial da aplicação
- [ ] Implementar tela de login e cadastro
- [ ] Implementar listagem de eventos
- [ ] Implementar filtros e favoritos
- [ ] Criar navegação básica entre páginas

### Entregável

Interface mínima para explorar eventos e interagir com o sistema.

## Semana 4 — Qualidade e portfólio

### Meta

Polir o projeto para ficar apresentável e demonstrável.

### Tarefas

- [ ] Adicionar testes no frontend
- [ ] Melhorar tratamento de erros
- [ ] Documentar funcionalidades e arquitetura
- [ ] Criar screenshots ou demo local
- [ ] Preparar README profissional

### Entregável

Projeto com demo funcional, documentação clara e aparência adequada para portfólio.

## Critérios de sucesso do roadmap

- O usuário consegue se cadastrar e entrar
- É possível buscar e visualizar eventos
- O fluxo principal funciona sem falhas grandes
- O projeto está documentado e pronto para demonstração
